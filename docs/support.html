Homelab Support & Help

Community-driven support and issue tracking

Homelab is a free, open-source project created and maintained for the homelab community. If you need assistance, wish to report a bug, or want to suggest new features, here are the best ways to get help:

1. Report a Bug or Crash

If you experience an issue with connecting to a service, layout glitches, or unexpected behavior:

  • Check the GitHub Issues tracker to see if it has already been reported.
  • Open a new issue with details about your Android version, device model, and the service type/version you are connecting to.

2. Request a New Service Integration

Homelab supports 34+ services and continues to expand. If you'd like support for another self-hosted service, please submit a feature request on GitHub with API documentation links.

3. Security & Vulnerability Reports

If you discover a security vulnerability, please open a private GitHub advisory or create an issue tagged with security.
